**Epistorm-Mix dataset**

Epistorm-Mix is the first dataset containing contact patterns for all ages of the US population collected during the post-pandemic era from a statistically representative sample.

The dataset contains sociodemographic characteristics of respondents and each contact, such as age, sex, and race/ethnicity. Moreover, the data includes a set of additional key information on the contact, such as the relationship between the respondent and the contacted individual

This folder contains the final respondent-level and contact-level data for use in further analyses of contact patterns and modeling of infectious disease dynamics. 

In particular, you will find: 
- a respondent-level dataset with all characteristics of the respondent;
- a contact-level dataset with all the characteristics of each reported contact;
- codebook for respondent-level dataset;
- codebook for contact-level dataset
  
Codebooks contain: variable descriptions, response options for each variable, and the name of the question in the survey questionnaire associated with each variable.

Tutorials on how to use this data can be found [here](../../tutorials).
