
This folder contains cleaned data before imputations and is provided here for reproducibility purposes and potential sensitivity analyses if an alternative missing strategy is considered. 
This data contains missing data. Multiple contacts (<30 contacts reported as a group) and numerous contacts (>= 30 contacts reported as a group) are reported as a set of variables in respondent data here: "resp_edun_xx" for either multiple or numerous contacts with children/students of xx age group; mc_ncont for other numerous/multiple contacts.

We encourage utilizing [imputed data](../imputed_data) for any mathematical modeling and further contact pattern analyses.
