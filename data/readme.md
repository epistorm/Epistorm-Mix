# Data 

## Imputed Data 
We recommend using imputed data for any further analysis of contact patterns.  
Imputed data folder contains individual-level data ready for data analysis, including:
- a respondent-level dataset with all characteristics of the respondent;
- a contact-level dataset with all the characteristics of each reported contact;
- codebook for respondent-level dataset;
- codebook for contact-level dataset

Codebooks contain: variable descriptions, response options for each variable, and the name of the question in the survey questionnaire associated with each variable. 

## Other Data

   ### External Data
   The external data used in this analysis include pre-pandemic US contact matrices, contact matrices from other countries, and age structure data. 
   For more information on where the data was taken, refer to the folder: 
   [external-data](./external_data)

   ### Gam Specifications
   This folder contains the specifications of the GAM models for the analysis of the total number of contacts and the number of non-household contacts. More details on the specification selection can be found in the Supplementary Materials of the [manuscript]().

   ### Mathematical Modeling Data
   This folder contains all the data necessary to perform the mathematical modeling described in [manuscript](). This data is necessary to run the code in the [mathematical modeling][code/mathematical-model] folder.

   ### Raw Data
   Raw data is provided here for reproducibility purposes and potential sensitivity analyses for alternative missing data imputation strategies. The folder contains the respondent-level and contact-level datasets as well as the codebooks for each dataset.
